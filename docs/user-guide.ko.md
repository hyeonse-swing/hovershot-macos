# HoverShot 사용자 가이드

## 무엇을 하는 앱인가

`HoverShot`은 macOS 메뉴바 앱입니다.

이 앱으로 할 수 있는 일:
- 화면 일부 캡처
- 윈도우 캡처
- 캡처 결과를 다른 앱 위에 띄워두기
- 저장된 샷 검색 및 관리
- 영역 또는 윈도우 녹화
- 녹화 트림 및 GIF 내보내기

[English version](user-guide.md)

## 설치 및 첫 실행

### 팀 패키지를 받은 경우

1. 받은 zip 파일을 압축 해제합니다.
2. `HoverShot.app`을 `/Applications` 또는 원하는 앱 폴더로 옮깁니다.
3. `HoverShot.app`을 실행합니다.
4. macOS 메뉴바에서 아이콘을 찾습니다.

### macOS가 앱 실행을 막는 경우

현재 빌드는 로컬 서명 상태이며 notarization이 되어 있지 않을 수 있습니다.

이 경우:
1. `HoverShot.app`을 우클릭합니다.
2. `열기`를 누릅니다.
3. 실행을 허용합니다.

그래도 막히면:
1. `시스템 설정 > 개인정보 보호 및 보안`으로 이동합니다.
2. 차단된 앱 실행을 허용합니다.
3. 다시 실행합니다.

## 필요한 권한

상황에 따라 다음 권한이 필요합니다.
- `화면 기록`
- 녹화 시 마이크를 쓸 경우 `마이크`

중요:
- `화면 기록` 권한은 `HoverShot.app`에 줘야 합니다.
- 권한을 허용한 뒤 앱을 한 번 완전히 종료하고 다시 실행해야 합니다.
- 과거에 `swift run`으로 실행했다면, 권한 대상이 터미널이 아니라 현재 사용하는 앱 번들인지 확인해야 합니다.

## 메인 메뉴

메뉴바 앱에는 현재 다음 항목들이 있습니다.
- `Settings...`
- `Open Shots Browser`
- `Open Recordings Browser`
- `Import From Clipboard`
- `Capture Area`
- `Capture Window`
- `Re-capture Last Area`
- `Timed Capture`
- `Record Area`
- `Record Window`
- 녹화 중 `Pause`, `Resume`, `Marker`, `Stop` 관련 항목

## 스크린샷 기본 사용 흐름

### 영역 캡처

1. 메뉴바 아이콘을 클릭합니다.
2. `Capture Area`를 선택합니다.
3. 원하는 영역을 드래그합니다.
4. 마우스를 놓으면 플로팅 샷이 생성됩니다.

### 윈도우 캡처

1. 메뉴바 아이콘을 클릭합니다.
2. `Capture Window`를 선택합니다.
3. 공유 가능한 윈도우를 고릅니다.
4. `Capture`를 누릅니다.

### 마지막 영역 다시 캡처

`Re-capture Last Area`를 사용하면 마지막으로 성공한 영역을 다시 지정하지 않고 바로 재캡처할 수 있습니다.

### 타이머 캡처

`Timed Capture`는 선택한 영역을 바로 찍지 않고 잠깐 기다렸다가 캡처하고 싶을 때 씁니다.

예:
- 메뉴를 미리 열어둬야 할 때
- hover 상태를 잡고 싶을 때
- 잠깐 나타나는 팝오버를 캡처하고 싶을 때

동작 순서:
1. `Timed Capture`를 선택합니다.
2. 먼저 캡처할 영역을 지정합니다.
3. 카운트다운이 진행됩니다.
4. 시간이 끝나면 지정한 영역이 자동으로 캡처됩니다.

## 플로팅 샷

캡처 후 결과는 플로팅 윈도우로 표시됩니다.

가능한 동작:
- 위치 이동
- 가장자리 리사이즈
- 스크롤로 투명도 조절
- 우클릭으로 추가 기능 사용

### 우클릭 메뉴

대표 항목:
- `Copy Image`
- `Export...`
- `Reveal in Finder`
- `Annotate...`
- `Fit to Screen`
- `Reset Size`
- 표시 범위 관련 옵션
- 투명도 프리셋
- `Ignore Mouse Clicks`

### 크기 조절

- 원본 캡처보다 더 작게 줄일 수 있습니다.
- `Fit to Screen`은 현재 디스플레이 기준으로 맞춰줍니다.
- `Reset Size`는 기본 표시 크기로 되돌립니다.

### 클릭 스루를 잘못 켠 경우

`Ignore Mouse Clicks`를 켠 뒤 다시 상호작용이 안 되면:
1. 메뉴바 앱을 엽니다.
2. `Floating Shots`를 찾습니다.
3. 해당 샷을 선택합니다.
4. `Ignore Mouse Clicks`를 다시 끕니다.

## Shots Browser

`Open Shots Browser`로 엽니다.

가능한 작업:
- 제목, OCR 텍스트, 태그, 노트 기준 검색
- OCR 결과 확인
- 제목 변경
- 태그 / 노트 편집
- 즐겨찾기 지정
- 샷 다시 열기
- 주석 편집
- 복사
- 내보내기
- Finder에서 위치 보기
- 하나 또는 여러 개 삭제

### 검색과 편집 내용 보존

- 목록 하단에서 현재 검색 결과 수와 전체 항목 수를 확인할 수 있습니다.
- 검색 결과가 없으면 `Clear Filters`로 검색과 필터를 초기화합니다.
- 목록을 더블 클릭하면 샷을 플로팅 창으로 엽니다.
- 제목·태그·노트의 미저장 변경은 다른 항목으로 이동하거나 검색·새로고침해도 유지됩니다. 샷은 `Save Details` 또는 `⌘S`로 저장합니다.
- 창을 닫거나 앱을 종료할 때 변경 내용이 남아 있으면 저장·취소·버리기를 선택합니다.
- 강제 종료나 시스템 장애가 나면 메모리에 보관된 미저장 변경은 복구되지 않습니다.

### 다중 선택 삭제

왼쪽 목록에서 여러 항목을 선택한 뒤 한 번에 삭제할 수 있습니다.

우클릭 메뉴로도 삭제할 수 있습니다.

## 주석 기능

샷을 열고 `Annotate...`를 선택합니다.

지원 도구:
- `Highlight`
- `Redact`
- `Arrow`
- `Step`
- `Text`

`Save`를 누르면 결과가 다음 곳에 반영됩니다.
- 플로팅 샷
- 브라우저 미리보기
- 복사 / 내보내기 결과
- 저장된 라이브러리 항목

## 클립보드 가져오기

`Import From Clipboard`로 가져올 수 있는 것:
- 이미지
- 텍스트
- Finder에서 복사한 지원 비디오 파일 참조

텍스트는 샷 카드 형태로 저장됩니다.

## 녹화 기본 사용 흐름

### 영역 녹화

1. 메뉴바 아이콘을 클릭합니다.
2. `Record Area`를 선택합니다.
3. 녹화할 영역을 드래그합니다.
4. 녹화 중 메뉴바 컨트롤을 사용합니다.

### 윈도우 녹화

1. 메뉴바 아이콘을 클릭합니다.
2. `Record Window`를 선택합니다.
3. 녹화할 윈도우를 고릅니다.
4. `Record`를 누릅니다.

### 녹화 중 컨트롤

녹화 중 사용할 수 있는 항목:
- `Pause Recording`
- `Resume Recording`
- `Add Edit Marker`
- `Stop Recording`

현재 동작 방식:
- pause / resume은 세그먼트 방식으로 동작합니다.
- resume 후에는 같은 세션의 다음 파트 파일로 이어집니다.

## Recordings Browser

`Open Recordings Browser`로 엽니다.

가능한 작업:
- 녹화 목록 탐색
- 재생 미리보기
- 제목 / 노트 / 즐겨찾기 편집
- 열기
- Finder에서 보기
- 트림
- GIF 내보내기
- 삭제

녹화 상세 화면은 작은 창에서 스크롤할 수 있습니다. 제목·노트·즐겨찾기를 편집한 뒤 `Save Details`를 눌러 저장하세요. 다른 항목을 선택하거나 검색해도 미저장 내용은 유지되며, 닫기·종료 시 저장 여부를 확인합니다.

## 녹화 트림

1. `Recordings Browser`에서 녹화를 선택합니다.
2. `Trim...`을 누릅니다.
3. 시작 / 끝 구간을 조정합니다.
4. 잘린 영상을 내보냅니다.

## GIF 내보내기

1. `Recordings Browser`에서 녹화를 선택합니다.
2. `Export GIF`를 누릅니다.
3. 저장 위치를 선택합니다.

## 설정과 단축키

메뉴바 앱에서 `Settings...`를 엽니다.

단축키 설정에서 가능한 작업:
- 전역 단축키 지정
- 단축키 제거
- 기본값 복원

규칙:
- `Command`, `Shift`, `Option`, `Control` 중 최소 하나는 포함해야 합니다.
- 단축키 입력 중 `Esc`를 누르면 입력을 취소합니다. 설정 창을 닫거나 다른 창으로 이동해도 입력을 취소합니다.
- 이미 사용 중인 단축키를 다른 액션에 지정하면 기존 액션에서는 제거됩니다.

설정 가능한 대표 액션:
- 영역 캡처
- 윈도우 캡처
- 마지막 영역 재캡처
- 타이머 캡처
- Shots Browser 열기
- Recordings Browser 열기
- 영역 녹화
- 윈도우 녹화
- 마커 추가
- 녹화 중지

## 저장 위치

대표 경로:
- 샷 메타데이터: `~/Library/Application Support/HoverShot/shots.json`
- 녹화 파일: `~/Movies/HoverShot`

직접 내보낸 결과물은 사용자가 선택한 위치에 저장됩니다.

## 문제 해결

### 화면 기록 권한을 계속 물어보는 경우

권한이 `HoverShot.app`에 들어갔는지 확인하세요. 터미널에만 들어가 있으면 안 됩니다.

그 다음:
1. 앱을 종료합니다.
2. 다시 실행합니다.

### 플로팅 샷이 너무 크게 뜨는 경우

다음 방법을 사용하세요.
- 가장자리 드래그로 직접 줄이기
- 우클릭 `Fit to Screen`
- 우클릭 `Reset Size`

### 클릭 스루를 실수로 켠 경우

메뉴바 앱에서:
1. `Floating Shots`
2. 해당 샷 선택
3. `Ignore Mouse Clicks` 해제

### 브라우저 창이 엉뚱한 디스플레이에 뜨거나 크기가 이상한 경우

`Shots Browser`와 `Recordings Browser`는 현재 마우스가 있는 디스플레이 기준으로 열리고, 그 화면의 `visibleFrame` 안으로 크기가 제한됩니다.

위치가 이상해 보이면:
1. 원하는 디스플레이로 마우스를 옮깁니다.
2. 메뉴바에서 브라우저를 다시 엽니다.

### 캡처나 녹화 결과가 이상한 경우

가장 먼저 해볼 일:
1. `HoverShot`을 종료합니다.
2. 다시 실행합니다.
3. 같은 작업을 한 번 더 시도합니다.

그래도 반복되면 다음 정보를 함께 정리해 두는 것이 좋습니다.
- 어떤 기능을 눌렀는지
- 어떤 모니터 구성인지
- 문제가 캡처, 플로팅 샷, 브라우저, 내보내기 중 어디서 났는지
